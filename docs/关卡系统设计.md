# 关卡系统设计（含游戏化机制）

> 目标：像打游戏一样培养学生的技能，让同学们"愿意来、留下来、想通关"。
> 游戏化不追求花哨动效，走"专业评测风"：工业感徽章、硬朗几何、克制反馈（符合品牌风格）。

## 一、核心玩法（原需求保留）

1. **多关卡**：可发布多个关卡（51 单片机 / 物联网 / 电赛 / 无人机…），每关独立配置。
2. **关卡内任务**：每关可发布若干任务，与任务系统一致——提交（可传图片/视频）、审核、打分。
3. **任务图片能力**：任务与关卡任务支持"任务图（发布者示例/示意图）"与"完成图/完成视频（学生上传）"；发布者也可发示例视频。
4. **评论系统**：关卡任务下评论区，所有人可交流；评论支持上传**图片与视频**（富评论区）。
5. **通关墙**：每关可见已通关同学的完成情况（提交预览 + 评分 + 详细记录），可点进详情。
6. **分数可配置**：每关满分/评分规则后台可改。
7. **审核人管理**：每关可设多名审核人（打分、精选、留言），可随时增删，便于交接。

## 二、游戏化机制（新增）

### 成长层 —— "我在变强"的持续驱动
| 机制 | 说明 | 落地要点 |
|---|---|---|
| **章节/技能线** | 关卡按章节组织（基础→进阶→大师），同类型关卡成一条"技能链"；通关前置才解锁后关 | 关卡表：`chapter`、`chain`（类型线）、`order`、`require_pass` |
| **技能进度图** | 首页/关卡 tab 展示每类技能链（进度条+节点+锁/旗），直观看到解锁进度与下一步 | 前端卡片地图，数据来自关卡+通关记录聚合 |
| **经验值与等级** | 通关获得 EXP 累计升级，头衔随等级变化（学员→工匠→专家→大师） | 复用积分体系，新增 `exp`、等级映射表；头衔显示在头像/详情 |
| **三星完美通关** | 评分 1-5 换算星：通过≥3★、优秀≥5★；集齐满星解锁金色徽章 | 复用 task.score，`stars` 派生字段 + 达标徽章 |

### 成就层 —— 收集欲 & 损失厌恶
| 机制 | 说明 | 落地要点 |
|---|---|---|
| **通关徽章掉落** | 每关通关掉落专属徽章（51 单片机芯片样、无人机翼形…）；集齐类型全套解锁隐藏称号 | 徽章表 + 头像/主页展示位；几何工业风 SVG |
| **连续挑战 Streak** | 连续提交/打卡保持"🔥 连续 N 天"，断签归零 | 每日参与去重求最长连续段，展示在个人卡 |
| **首通 / 限时奖励** | 关卡首通额外积分；学期内"XX 冲刺周"双倍积分 | 关卡记录 `first_pass_by` + 活动开关（后台配置） |
| **重修冲分（二周目）** | 已通关可重刷更高分/称号，取最优记录保留 | 通关记录取最高分，`best_score/best_at` |

### 社交层 —— 荣誉上榜 & 良性竞争
| 机制 | 说明 | 落地要点 |
|---|---|---|
| **通关荣誉墙（强化）** | 每关顶部通关榜：姓名+提交预览+评分，点进详情；榜上有名的荣誉驱动 | 已在核心玩法 5，前端置顶展示 |
| **通关广播动态** | 通关时写实时动态：「张三 通关了【51 单片机关卡】⭐」，可被点赞 | 复用 news/feed 生成 + 通知 |
| **精选作品 Best-of** | 审核人可"精选"优秀提交，置顶展示并额外加分，形成上精选目标 | `featured` 标记 + 精选位 |
| **评论区点赞/热度** | 评论可发图/视频 + 点赞，高赞不沉底、展示热度 | 评论表加 `likes` |

## 三、数据模型草图

```
Level（关卡）
  id, title, chain(技能线), chapter, order, score_limit(满分/可改),
  require_pass(前置关卡), description, cover(封面/徽章图), status,
  featured 配置, activity(限时活动开关), created/updated

LevelTask（关卡任务，关联任务）
  id, level_id, task_id / task_body(独立副本), kind(link|inline)

PassRecord（通关/提交记录）
  id, level_id, member_id, score, stars, featured, first_pass(首通),
  best_score/best_at, reviewer_id, opinion, media(json: 完成图/视频),
  submitted_at, reviewed_at

LevelReviewer（关卡审核人）
  id, level_id, member_id, can_review/can_featured, added_by, active

LevelComment（关卡评论）
  id, task_id/pass_ref, member_id, content, media(json: 图片/视频), likes, parent_id, created

LevelBadge（徽章/成就）
  id, chain, tier, title, icon(svg路径), desc, condition(json: 通关数/满星/首通/streak)

MemberLevelProfile / exp_titles（等级）
  member_id, exp, level, titles[]
```

## 四、与现有系统的衔接

- **任务/审核/打分**：直接复用 tasksapp（提交、上传、审核、评分、通知都已有）
- **积分/排行榜**：复用 points 体系；新增 exp 与头衔、多维度榜单（周热榜/通关榜/互助榜）
- **通知**：进出审核、通关、精选、点赞接入既有 notify
- **媒体**：图片/视频统一走 `/media/` 鉴权；视频播放前提示编码需 H.264（沿用 HEVC 排查经验）
- **权限**：新增 `page:levels`、`action:level.manage`、`action:level.review`、`action:level.comment` 等权限点，接权限矩阵

## 五、游戏化个人主页（成员详情页升级）

> 目标：把「成员详情」做成"游戏主页"——一眼看到这个人的**实力**与**活动**，让人忍不住点进来比较。

### 1. 主页头卡（身份 + 荣誉）
- 头像 + **等级头衔**（学员→工匠→专家→大师）+ 当前连续挑战天数（🔥）
- **徽章墙**：通关徽章、成就徽章横向铺开（悬停显示说明），未获得的置灰（收集欲）
- 顶部露出「总 EXP / 总积分 / 通关数 / 最擅长技能线」四格快照
- 本人视角：右上角「编辑主页签名」；他人视角：提供「关注/点赞应援」

### 2. 实力可视化（他的"段位"）
- **技能雷达图**：六维评分（硬件 / 软件 / 调试 / 文档 / 协作 / 创新），由该成员各技能线的通关数与评分推导，六边形对比直观
- **技能线进度链**：每类技能线一条进度条（与关卡进度图一致的视觉），展示解锁到第几章、差一关到下一段位
- **星级/最高分战绩**：各关卡最高三星与最高分小记，优秀/精选作品标记亮色

### 3. 活动可视化（他在做什么）
- **动态时间线**：打卡、提交、通关、审核通过、发评论、积分变动，按时间汇总成流
- **月度活动热力图**：30 天活跃热力（复用打卡热力格，扩展到"任意操作"），一眼看出此人活跃度
- **近期高光**：最近一次通关/精选/点赞最多的作品置顶

### 4. 社交与比较驱动（让人愿意点 vs 让人愿意被人点）
- 全站各处可点头像/名字进入主页（成员列表、排行榜、评论、动态、通关墙）
- **上榜入口**：排行榜/荣誉墙点击即进主页，主页自己做"迷你战绩对比条"（你 vs 他：等级/积分/通关数）
- **主页访客/应援计数**：被浏览次数与点赞应援可见——虚荣心驱动互相访问
- 本人主页提供"我的成就进度"清单：还差几个徽章/哪类满星，引导继续通关

### 5. 隐私与权限
- 公开范围：等级/徽章/技能/活动流/战绩——**全员可见**（这才有比较动力）
- 隐私边界沿用现有裁剪：联系方式/手机/邮箱/备注**不展示给他人**
- 超级管理员可对极端成员隐藏主页入口（罕见，无需优先）

### 6. 落地依赖
- 数据：依赖关卡系统（PassRecord/徽章/EXP）+ 现有积分/打卡/任务/评论
- 实现：改造 `memberDetailPage`（memberDetailPage 已具备任务/借用/打卡/日志面板，扩成游戏主页布局）；雷达图/热力图纯 SVG
- 排期：主页头卡+技能线+活动流 = P1；雷达图/比较条/应援 = P2；与关卡 P1/P2 同步推进

## 六、分阶段排期

- **P0（先跑通核心玩法）**：关卡 CRUD + 技能进度图 + 关卡任务（复用任务/审核/评分）+ 通关墙 + 分数后台配置 + 审核人增删 + 任务图片上传
- **P1（游戏化反馈 + 主页雏形）**：通关徽章掉落 + 经验等级头衔 + 三星体系 + 首通/限时奖励 + 通关广播动态 + **游戏主页头卡（等级/徽章墙/四格快照）+ 技能线进度链 + 活动时间线**
- **P2（社交与留存）**：富评论（图/视频/点赞）+ 精选作品 + Streak 连续挑战 + 多维度排行榜 + 重修冲分 + **主页雷达图/对比条/应援/访客计数 + 月度活跃热力图**

> 说明：本篇为设计文档，仅规划；P0 起逐步实现，每期完成按项目测试流程验收后再部署。
