# 具身智能实验室网站首页设计方案

> 版本 v1.0 · 2026-09-22 · 目标页面：https://wuyuan.me/ （替换 `/opt/lab/homepage/index.html` 即上线）

---

## 一、定位与受众

网站首页承担**双重角色**：

| 角色 | 说明 |
|------|------|
| 对外门面 | 展示实验室研究方向与成果，面向招生、学术同行、合作企业 |
| 对内入口 | 管理系统（硬件借还、任务、签到、智能体）的唯一门户入口 |

**目标受众优先级**：潜在学生（保研/考研/大创）> 学术同行 > 合作方 > 实验室成员（日常从首页进管理系统）。

---

## 二、页面结构（单页滚动 + 锚点导航）

```
┌─────────────────────────────────────────────┐
│ ① 导航栏  Logo | 研究方向 团队 动态 加入我们 | [进入管理系统] │
├─────────────────────────────────────────────┤
│ ② Hero 首屏                                 │
│    具身智能实验室                            │
│    一句话定位 + 主视觉 + 两个 CTA             │
├─────────────────────────────────────────────┤
│ ③ 研究方向  4~6 张方向卡片                    │
├─────────────────────────────────────────────┤
│ ④ 最新动态  论文/获奖/新闻（时间线，先放 3~4 条）│
├─────────────────────────────────────────────┤
│ ⑤ 团队  负责人 + 学生（头像卡片网格）           │
├─────────────────────────────────────────────┤
│ ⑥ 加入我们  招生方向 + 联系邮箱                │
├─────────────────────────────────────────────┤
│ ⑦ Footer  地址 · 邮箱 · 管理系统入口 · 备案号    │
└─────────────────────────────────────────────┘
```

各板块要点：

1. **导航栏**：滚动时吸顶 + 半透明毛玻璃；「进入管理系统」做主按钮样式（最醒目），保持现有 `/login/` 链接不变。
2. **Hero 首屏**（决定第一印象，最重要）：
   - 标题：`具身智能实验室` + 英文 `Embodied Intelligence Lab`
   - Slogan 候选：`让智能拥有身体，让身体拥有智能` / `感知 · 决策 · 行动 —— 打通虚拟与现实的机器人智能` / `我们研究能与世界交互的智能体`
   - 主视觉：实验室真机照片（机械臂/人形机器人/移动底盘）**优先用实拍**；没有合适照片时先用 AI 生成图过渡
   - CTA：`探索研究方向`（锚点）+ `进入管理系统`（/login/）
3. **研究方向**：卡片式，每张 = 图标/小图 + 方向名 + 两行简介。具身智能方向建议（按实际情况取舍 4~6 个）：
   - 视觉-语言-动作模型（VLA）
   - 灵巧操作与手部技能
   - Sim2Real 与仿真训练
   - 人形/足式机器人
   - 多模态感知与具身问答
   - 强化学习与机器人学习
4. **最新动态**：纵向时间线，条目类型打标签（`论文` `获奖` `新闻` `招生`）。首期放 3~4 条即可，结构留好，以后替换。
5. **团队**：负责人大卡片（照片 + 职称 + 研究简介 + 邮箱），学生小卡片网格（照片 + 姓名 + 方向标签）。照片没齐先用首字母占位头像。
6. **加入我们**：面向招生的一段话 + 报考方向 + 联系邮箱 + （可选）导师主页链接。
7. **Footer**：学校/学院名称、地址、邮箱、管理系统入口，**必须包含 ICP 备案号**（域名已备案，按工信部要求需在页面底部展示备案号并链接到 beian.miit.gov.cn）。

## 三、视觉风格

**推荐方向 A：深色科技风**（与现有占位页一致，延续成本低）

| 元素 | 规格 |
|------|------|
| 背景 | 深蓝黑 `#0B1220`，分区可用 `#101A2E` |
| 强调色 | 电光蓝 `#4EA1FF`（主）+ 青色 `#37E2C8`（辅，用于数据/动效点缀） |
| 正文 | `#E6EDF7`，次要文字 `#9FB3D1` |
| 字体 | 中文：思源黑体 / HarmonyOS Sans；英文标题：Space Grotesk / Inter |
| 点缀元素 | 细网格线、机器人关节/骨架线框、电路走线动画（克制，不超过 2 处） |
| 圆角/留白 | 卡片 14px 圆角、区块间距 96px，整体大气不拥挤 |

备选方向 B：浅色学术风（白底 `#FAFBFD` + 学院蓝 `#1B4B8F`），更像传统高校课题组主页，严肃但视觉冲击弱。**两者不混用，选定一个贯彻到底。**

## 四、技术实现

- **架构不变**：仍是单文件静态页 `/opt/lab/homepage/index.html`，CSS/JS 内联或拆分为同目录文件，覆盖即上线，无需重启。
- **性能**（服务器带宽仅 3Mbps，务必注意）：
  - 图片全部 WebP，单图 ≤ 200KB，首屏主图 ≤ 300KB
  - Hero 图加 `loading="eager"` + 模糊占位；视口外图片 `loading="lazy"`
  - 不引入大型框架（React/Vue），原生 HTML/CSS + 少量 JS
- **动效**：滚动渐入（IntersectionObserver）、卡片悬浮微动效，总量克制
- **可维护性**：首页放进 git 仓库（建议 `homepage/` 目录），改版走 git 提交
- **未来扩展**：
  - 「最新动态」可改为读取静态 `news.json`（成员不用改 HTML 也能加新闻）
  - 可选：管理系统发布的公开通知自动同步到首页（需要后端小接口，二期）
